**Description**
Sentinel AI is an AI powered incident investigation platform that uses NLP and semantic search to identify historically similar production incidents from their descriptions.
The goal is to help Engineers investigate production issues faster by finding relevant past incidents based on meaning rather than exact keyword matching.

**Problem Statement**
In Production environments, engineers frequently encounter incidents such as database connection failures, API errors, service outages and performance bottlenecks.

Finding previously logged incidents can be time consuming , especially when the incident description uses different terminology to describe similar problem.

Sentinel AI addresses this problem uses semantic similarity search.
